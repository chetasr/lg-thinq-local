# LG ThinQ Local AC Control — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fully local control of an LG wall-mounted AC (`RSNQ19KWZE.ANLG`) from Home Assistant, by adding RSNQ support to rethink-cloud and running it as an HA add-on.

**Architecture:** rethink-cloud impersonates LG's ThinQ cloud on the LAN (DNS overrides on an OpnSense router point `common.lgthinq.com`/`eic.lgthinq.com` at the rethink host). The AC is re-provisioned to rethink, then run in bridge mode (forwarding to the real cloud) while its TLV protocol is reverse-engineered from captures. A new device class translates the schema to Home Assistant MQTT discovery. Finally rethink is packaged as an HA add-on and run pure-local (bridge off).

**Tech Stack:** Node.js/TypeScript (rethink), Docker, OpnSense Unbound host overrides, Mosquitto MQTT, Home Assistant, wideq (modelJson fetch).

**Spec:** `docs/superpowers/specs/2026-09-12-lg-thinq-local-ac-design.md`

## Global Constraints

- AC model: `RSNQ19KWZE.ANLG`; modem `clip_hna_v1.9.237_RT`; it is a ThinQ2 device.
- This laptop (RE-phase rethink host): Ethernet IP `10.10.1.75/22`, has Docker, Node 24, Wi-Fi (`wlp3s0`) that can join the AC's SoftAP.
- Router: OpnSense with Unbound; user has admin access.
- rethink config `hostname` must be a DNS name (not an IP, not mDNS `.local`); we use `rethink.lan`.
- DNS overrides must have non-zero TTL (rethink wiki: modems mishandle zero TTL).
- rethink's own outbound traffic must NOT hit the DNS overrides (breaks bridge mode) — solved via `/etc/hosts` pinning on the laptop.
- Feature scope (spec): must = power, target temp, mode, room temp; nice = fan, swing, jet, quiet; bonus = energy, filter, diagnostics. No timer/schedule logic in the device class.
- If the device rejects the non-LG cloud or provisioning can't be made to work: STOP and reevaluate with the user. No hardware fallback is preset.
- Reference docs: rethink wiki pages `Installing-rethink‐cloud`, `Bridge`, `SetupProtocol`, `Adding-support-for-a-new-device`, `Appliance:RAC_056905_WW`; local clone of rethink lives at `~/lg-thinq-local/rethink`.
